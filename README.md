# RUPA

RUPA is a React + Vite website for a technology ecosystem with two complementary directions:

- **Our innovations:** products, software, experiments, and research created within RUPA.
- **Discover:** AI and technology announcements, models, products, research, and learning resources from external official sources.

## Current frontend

The current milestone contains the public homepage structure:

- Animated RUPA logo introduction
- Responsive navigation
- Hero section
- About / Build, Discover, Learn section
- Our innovations (currently Lumina and Orbit)
- Discover preview (AI news, models and products, research and learning)
- Footer

The Discover cards are currently structural placeholders. An external-source collection pipeline, backend, database, admin dashboard, and live content have not been implemented yet.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
